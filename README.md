Smart Street Light

Project Overview

The Smart Street Light is a beginner-friendly electronics project that automatically switches a street light ON in darkness and OFF in bright conditions.

Components Used

- Arduino Uno
- LDR (Photoresistor) sensor
- LED
- 220-ohm resistor
- Jumper wires

Working Principle

The LDR detects the surrounding light level and sends an analog signal to the Arduino. The Arduino reads the sensor value and controls the LED based on a programmed threshold.

- Dark environment: LED ON
- Bright environment: LED OFF

Tools Used

- Wokwi Arduino Simulator
- Arduino C/C++ programming

Objective

To learn basic electronics, sensor interfacing, Arduino programming, and automatic lighting control.
